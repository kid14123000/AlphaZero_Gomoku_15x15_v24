## v19 — value 头换隐藏层（Kimi 三步走）：继承 v18 it180 空池重训（2026-08-26 启动）

### 一句话
value 头是 v18 唯一卡点（败局库崩 22-25% / 视角对称长尾零收敛 / PK 白窗口三连崩），修复候选排序 GAP > 一致性正则 > 加隐藏层，用户拍板先试**主流式隐藏层 value 头（B 方案）+ Kimi 三步走冻结训练**——继承 v18 it180 全部主干+policy 学习成果，只换 value 头结构，空池重训。

### 架构（B 方案，主流 AlphaZero/Leela 式）
- **v18 value 头**（被替换）：`conv(128→1,3×3) → BN → ReLU → flatten(225) → fc(225→1) → tanh`（全家族最简，单 FC 直出，~1.4K 参数）
- **v19 value 头**（新）：`conv(128→1,3×3) → BN → ReLU → flatten(225) → fc1(225→128) → ReLU → fc2(128→1) → tanh`（~30K 参数，Leela/junxiaosong 同款）
- **继承关系图示（关键设计点，2026-08-26 用户确认）**：
  ```
  v18: conv(128→1,3×3) → BN → ReLU → flatten → fc(225→1) → tanh
                     └──── 继承（形状相同）────┘   └─ 换掉 ─┘
  v19: conv(128→1,3×3) → BN → ReLU → flatten → fc1(225→128) → ReLU → fc2(128→1) → tanh
  ```
  只换 value 头的**打分层（fc）**，特征提取层（value_conv/value_bn）形状相同**逐层 torch.equal 完全继承**（it180）——大幅缩短启动时间：新头只需学"特征→打分"映射，不必重学"读棋盘威胁"
- **半继承启动红利实测（2026-08-26，it180 未学习前的随机 fc 状态）**：
  | 棋形 | v19 半继承（conv 继承+fc 随机） | 全随机（conv+fc 都随机） |
  |---|---|---|
  | 黑活四 | **+0.942** ✅ | -0.051 ❌ |
  | 黑活三 | **+0.659** ✅ | -0.052 ❌ |
  | 白活三 | **+0.461** | -0.053 ❌ |
  | 空盘 | -0.032 ✅ | -0.054 |
  全随机 value 头对活四/活三完全无感（瞎猜）；半继承版开局就读对了——差别全在 value_conv/value_bn 这 1.4K 参数的特征提取层。继承特征层 + 冻结期专注学 fc 打分 → it180 学 1 代即修好 v18 花 180 代没解决的活三视角反号
- **主干 + policy 头完全不动**（8×ResBlock 128ch + conv(128→1,3×3)→log_softmax）
- **总参数**：2,399,621（v18 约 2.37M，+29K 全部来自 value 头）
- **设计理由**：主流均有 64-256 维隐藏层；v18 单 FC 直出是家族异类；隐藏层让 value 有中间表征空间学习"威胁模式→胜负"映射；v2 低秩化先例因 log-prob bug 污染不干净，不作为否决理由

### Kimi 三步走冻结训练（用户拍板冻结 10 代）
- **阶段 1（it180-189，10 代）**：冻结主干 + Policy 头，只训练新 value 头——让新头先学会"读取"主干已有特征，不破坏主干表示（policy_loss 照算但不反传更新冻结层）
- **阶段 2（it190 起）**：解冻全网络一起训练——让主干适应新 value 监督信号，微调特征提取
- **实现**：`set_freeze_value_only(True/False)` 只改 `requires_grad`（value_ 前缀保留，其余 False），**不重建 optimizer**（参数引用固定，requires_grad=False 梯度 None 自动跳过，避免 GradScaler 状态丢失）；主循环 `iteration < start + freeze_value_iters` 判断
- **继承兼容**：`load_checkpoint` pop 旧 `value_fc` 键 + strict=False——value_conv/value_bn 与 v18 同形状**逐层 torch.equal 完全继承**，fc1/fc2 随机初始化（验证通过）
